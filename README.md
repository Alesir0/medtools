# عيادة الأدوات — أدوات حساب سريرية

موقع ثابت (Static Site) بدون خادم خلفي، يحتوي على ثلاث أدوات:

1. **حاسبة جرعات طوارئ الأطفال** (`pediatric-dosing.html`) — تختار الدواء، تدخل الوزن، وتحصل على الجرعة.
2. **حاسبة HEART Score** (`heart-score.html`) — لتقييم خطورة ألم الصدر القلبي.
3. **مقياس غلاسكو للغيبوبة GCS** (`gcs.html`) — لتقييم مستوى الوعي.
4. **لوحة تحكم** (`admin.html`) — محمية بكلمة مرور، لإضافة/تعديل/حذف الأدوية وجرعاتها لكل كيلوغرام.

## طريقة رفعه على GitHub Pages (خطوة بخطوة)

1. أنشئ مستودعًا (Repository) جديدًا على GitHub، مثلاً باسم `med-tools`.
2. ارفع كل الملفات والمجلدات الموجودة هنا (`index.html`, `pediatric-dosing.html`, `heart-score.html`, `gcs.html`, `admin.html`, ومجلدي `css/` و`js/`) إلى جذر المستودع — إما بالسحب والإفلات من واجهة GitHub، أو عبر:
   ```bash
   git init
   git add .
   git commit -m "أول نسخة من عيادة الأدوات"
   git branch -M main
   git remote add origin https://github.com/USERNAME/med-tools.git
   git push -u origin main
   ```
3. من داخل المستودع على GitHub: **Settings → Pages**.
4. تحت "Build and deployment" اختر **Deploy from a branch**، والفرع **main**، والمجلد **/(root)**، ثم احفظ.
5. بعد دقيقة أو دقيقتين سيظهر رابط الموقع بالشكل:
   `https://USERNAME.github.io/med-tools/`

لا حاجة لأي إعداد إضافي — لا قواعد بيانات ولا خادم، الموقع HTML/CSS/JS بالكامل.

## ملاحظات مهمة عن لوحة التحكم

- كلمة المرور الافتراضية عند أول تشغيل: `admin123` — **يجب تغييرها فورًا** من داخل لوحة التحكم بعد أول دخول (قسم "تغيير كلمة المرور").
- الحماية بكلمة المرور تتم بالكامل من جهة المتصفح (client-side)، وهي مناسبة فقط لتقليل الوصول العرضي غير المقصود من الزوار العاديين — **وليست حماية أمنية حقيقية**، لأن أي شخص يملك أدوات مطوّر بالمتصفح يمكنه تجاوزها. لا تُدخل أي بيانات حساسة عبر هذا الموقع.
- بيانات الأدوية تُحفظ داخل `localStorage` في متصفح كل زائر على حدة. **التعديلات التي تجريها من جهازك لن تظهر تلقائيًا لزوار آخرين على أجهزتهم**، لأنه لا يوجد خادم مركزي يخزّن البيانات.
- لتوزيع قائمة أدوية موحّدة على الفريق:
  - عدّل القائمة الافتراضية مباشرة داخل `js/storage.js` (المتغيّر `DEFAULT_DRUGS`) قبل رفع الموقع، بحيث تكون هي القائمة التي يراها كل زائر جديد، أو
  - استخدم زر **"تصدير JSON"** في لوحة التحكم لتصدير القائمة الحالية، وشاركها مع الفريق ليستوردوها يدويًا (يتطلب إضافة كود استيراد بسيط إذا رغبتم بهذه الميزة الإضافية).
- إذا احتجتم لاحقًا إلى قائمة أدوية مشتركة فعليًا بين كل الزوار مع تحكم مركزي حقيقي، سيتطلب ذلك إضافة قاعدة بيانات وخادم خلفي (مثل Firebase أو أي API بسيط) — هذا خارج نطاق الموقع الساكن الحالي، لكن يمكن إضافته لاحقًا إذا رغبتم.

## إخلاء مسؤولية طبية

جميع الجرعات والمعايير المعروضة (جرعات الأدوية، معايير HEART Score، ومقياس GCS) هي قيم مرجعية شائعة الاستخدام في الأدبيات الطبية، ومخصصة كأداة مساعدة سريعة للكادر الطبي المؤهل فقط. يجب دائمًا مطابقتها مع البروتوكولات المعتمدة والمراجع الدوائية الرسمية في المنشأة الصحية قبل أي استخدام فعلي، ولا تُغني بأي شكل عن التقييم السريري المباشر للمريض.
